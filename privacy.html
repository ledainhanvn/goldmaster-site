Privacy Policy

Last updated: 20 October 2026

GOLD MASTER Uploader ("the tool") is a private application operated by a single individual, the owner of the YouTube channel "GOLD MASTER". It is not offered to the public and has no users other than the owner.

What the tool does

The tool uploads videos and thumbnails that the owner creates to the owner's own YouTube channel using YouTube API Services (videos.insert and thumbnails.set), with the scope https://www.googleapis.com/auth/youtube.upload.

Data we collect

The tool does not collect, store, share or sell personal data of any other person. It does not read data about other YouTube users or viewers. The only credential kept is the owner's own OAuth refresh token, stored as a protected secret in the owner's private environment and never published or shared.

YouTube API Services

The tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://security.google.com/settings/security/permissions.
